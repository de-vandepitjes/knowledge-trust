# Submission checklist (Builderbase)

Owner: ______

## Before final submission

- [ ] README: what it is, how to run, what is unfinished
- [ ] Repo is **public** and stays public until judging ends
- [ ] No secrets in git history (`git log -p | grep -i key` sanity check; `.env.local` never committed)
- [ ] `main` runs from a fresh clone: `npm ci && npm run dev`
- [ ] Aikido **before** screenshot (baseline scan, taken right after connecting the repo)
- [ ] Aikido issues fixed and marked resolved
- [ ] Aikido **after** screenshot
- [ ] Demo video < 3 min recorded (script below), uploaded, link works in incognito
- [ ] Short description written (problem → moment of doubt → what we built → why it's trustworthy)
- [ ] All links tested from a browser that is not logged in

## Demo video outline (< 3 min)

1. 0:00–0:30 The moment of doubt (persona, question, three conflicting sources)
2. 0:30–2:00 The product: find → understand → trust (show the trust signals, not just the answer)
3. 2:00–2:40 How it works in one breath + what's next
4. 2:40–3:00 Team + thanks

## Builderbase fields

- Description
- Demo video link
- GitHub repo link
